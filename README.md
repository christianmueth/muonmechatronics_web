# Christian Mueth's Blog

A focused personal blog for essays and working notes about technology, learning, creativity, and making useful things.

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. The homepage is implemented in `app/page.tsx`, with global presentation styles in `app/globals.css` and site metadata in `app/layout.tsx`.

## Validation

```bash
npm run lint
npm run build
```

## Deployment

The application is a Next.js site and can be deployed on Vercel or another platform that supports Next.js production builds.
